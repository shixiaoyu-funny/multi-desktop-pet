# Suki 桌面宠物

Suki 是一个运行在 Windows 桌面上的透明 WebM 桌宠。她可以站在桌面上、坐在任务栏或窗口边缘、被拖动、受重力掉落到鸭子坐，也能通过 AI 聊天、情绪阶段、语音播报和主动陪伴与用户互动。

项目使用 **Tauri 2 + Rust + WebView2**，角色以 **768×768、60fps、带 Alpha 通道的 VP9 WebM** 渲染。

> 代码位于本仓库的 `suki/windows` 分支；`raven/windows` 是同一套桌面宠物技术的 Raven 角色版本。

## 亮点

### 1. 真正的透明桌宠

- 透明窗口 + 双层 `<video>` 交叉淡入，动作切换没有硬切。
- Rust 侧维护角色像素掩膜，只在角色不透明像素上接收鼠标；透明区域点击穿透。
- 支持拖动、任务栏/窗口边缘吸附、全屏边界夹紧、系统托盘。
- **单实例运行**：重复启动不会出现第二只 Suki，而是弹出提示并退出。
- 工具箱支持随机切换、语音播报、好感度和**开机自启**开关；自启使用官方 `tauri-plugin-autostart`。
- 所有 23 个动作统一为 `scale = 1.0`、`offset = 0`，画面比例不漂移。

### 2. 重力与鸭子坐

- 开启重力后，拖拽松手或支撑消失会进入自由落体。
- 下落瞬间强制切换到 **鸭子坐待机**，不播放过渡、不排队。
- 落地后保持鸭子坐，形成“突然掉下来、马上坐好”的角色反应。
- 鸭子坐 / 正坐吸附线分别可调，适配不同屏幕缩放。

### 3. 23 个动作的完整状态机

| 类型 | 数量 | 动作 |
|---|---:|---|
| 待机 | 3 | 站姿待机、正坐待机、鸭子坐待机 |
| 触摸一次性动作 | 12 | 三种姿态 × 擦汗、撩头发、捂嘴笑、生气 |
| 喝奶茶 | 2 | 两个站立喝奶茶变体 |
| 姿态过渡 | 6 | 站↔正坐、站↔鸭子坐、正坐↔鸭子坐 |
| **合计** | **23** | |

状态机支持：

- 站姿 / 正坐 / 鸭子坐三种姿态；
- 同姿态直接切换、跨姿态自动播放过渡；
- 待机动作随机轮换；
- 点角色头部、肚子、腿部触发不同互动；
- 工具箱手动选姿态、预览动作。

### 4. 三姿态触摸互动

站姿、正坐、鸭子坐都拥有完整的触摸动作，不再只有站姿能播表情：

| 触摸部位 | 动作 | 说明 |
|---|---|---|
| 头部 | 擦汗 / 撩头发 | 每次随机二选一 |
| 肚子 | 捂嘴笑 | 被挠痒的反应 |
| 腿部 | 生气 | 害羞又嘴硬 |

- 每个姿态都有对应的 4 个动作素材；
- 动作结束回到**当前姿态**待机，不会强行切回站姿；
- 9 个回复池（3 姿态 × 3 部位），每池 7 条预制台词；
- 每次触摸在显示预制回复的同时，后台异步生成一句新的角色回复；
- 新回复会随机替换该池中的一个旧槽位，并持久化保存；
- AI 生成不阻塞当前互动，失败时保留原池。

### 5. 喝奶茶

- 工具箱中的独立「喝奶茶」按钮；
- 每个本地自然日最多 **2 次**，跨天自动重置；
- 每次由 AI 根据当前好感阶段决定增加 **3～7 点**好感；
- 同时由 AI 生成一句针对“被请喝奶茶”的简短回应；
- 两个喝奶茶动作变体随机播放，动作只能通过该按钮触发；
- 正坐 / 鸭子坐时会先站起来喝，喝完回到原姿态；
- 次数用完后按钮置灰，不会继续加好感或播放动作。

### 6. AI 聊天与工具调用

聊天气泡使用 `qwen3.8-flash`，并实现手写 ReAct 工具循环：

- **Bilibili 只读工具**：搜索、热门、视频详情、UP 主资料；
- **截图看屏**：把当前屏幕压缩成 JPEG，以 `image_url` 发给多模态模型；
- **应用启动**：扫描 Start Menu / UWP 应用，按名称启动软件；
- **沙盒终端**：只读 PowerShell 查询，限制命令、超时和输出长度；
- 工具结果会回注给模型，最终仍输出结构化动作 JSON。

工具全部只读，不支持下单、支付、加购物车、发消息或上传文件。

### 7. 好感度与情绪阶段

聊天不是固定人格，而是会随互动逐步变化：

- 四个阶段：拘谨讨好、活泼爱撒娇、极度依赖、绝望黑化；
- 每轮用户消息后由轻量模型评估好感变化，失败时使用本地关键词兜底；
- 好感度持久化到独立文件；
- 聊天 System Prompt 会按当前阶段动态变化；
- 点击「清空」会经过多段确认，并同时清空聊天历史、好感度，并恢复当天两次喝奶茶次数；
- 工具箱右上角以颜色徽章显示当前好感阶段。

### 8. 语音播报

- 使用 **Qwen-Audio-TTS**，通过官方 HTTP API 进行 SSE 流式合成；
- 音频在内存中拼接为 MP3，不写磁盘；
- 前端用 Blob URL 播放，兼容 Tauri 的 CSP；
- 服务端 `rate = 1.2`，语音节奏更快、更自然；
- 聊天窗口会等待语音真正开始后才输出第一个字，避免“字先出来、声音后到”；
- 文字保持 0.75 倍速逐字输出；
- 工具箱可手动开启/关闭语音，关闭时立即停止当前播放。

### 9. 主动陪伴

- 检测前台应用，把应用名交给轻量模型判断是否值得主动搭话；
- 对娱乐、工作、学习类应用生成一次性气泡；
- 支持按时间自动截屏看内容，再生成陪伴式闲聊；
- 这些主动气泡不进入聊天历史，不污染长期记忆；
- 全屏、隐私窗口、空闲状态可跳过。

### 10. DSH Web 插件

`dsh-plugin/` 包含同角色的 DSH 页面悬浮版：

- 复刻桌面版的站姿 / 正坐 / 鸭子坐动作与过渡；
- 用 SSE 接收 DSH 的 AI 活动状态，显示工作 / 查资料 / 完成 / 出错；
- 支持拖动、大小调整、姿态切换、开发者面板；
- 粉白主题与桌面版视觉统一。

## 技术栈

- **桌面框架**：Tauri 2、Rust、WebView2
- **视频**：VP9 WebM + Alpha，768×768 @ 60fps
- **前端**：原生 HTML / CSS / JavaScript，双层视频交叉淡入
- **窗口与物理**：Win32 API、全局光标轮询、透明窗口、像素掩膜命中
- **AI**：DashScope OpenAI 兼容接口、Function Calling / ReAct
- **语音**：Qwen-Audio-TTS HTTP + SSE、MP3 Blob 播放
- **构建**：Cargo、MSVC、Tauri CLI

## 运行

日常启动：

```text
启动桌宠.vbs
```

它会隐藏启动 `src-tauri\target\release\suki-winpet.exe`，不会弹出黑色控制台。

重新编译：

```bat
启动桌宠.bat
```

`启动桌宠.bat` 会构建 debug 版本并启动 `target\debug\suki-winpet.exe`；日常运行使用的是 release 版本。

需要 MSVC 环境，默认路径为 `D:\BuildTools\VC\Auxiliary\Build\vcvars64.bat`；路径不同请修改脚本中的 `VCVARS`。

也可以手动构建：

```powershell
cd src-tauri
cargo build
```

首次使用 AI 聊天/语音需要配置 `DASHSCOPE_API_KEY`，可在聊天窗口的「设置」里查看配置方法。

## 操作

- **拖动**：按住角色移动。
- **点击头部/肚子/腿**：触发不同互动与台词。
- **右键**：打开工具箱。
- **托盘菜单**：显示/隐藏、置顶、工具箱、退出。
- **工具箱**：大小、随机切换、吸附、重力、语音、好感度、退出。
- **聊天**：AI 回复、工具使用状态、好感度变化、清空记忆确认。

## 配置与数据

运行时数据位于：

```text
%APPDATA%\com.local.suki.winpet\
  config.json        窗口/吸附/重力/语音等设置
  chat_history.json  最近聊天记录
  affection.json     当前好感度
  milk_tea.json      每日奶茶次数与日期
```

应用标识为 `com.local.suki.winpet`，可执行文件为 `suki-winpet.exe`。

开发调试（debug 构建）可设置：

```powershell
$env:SUKI_OPEN_WINDOW = 'chat'   # chat / setup / toolbox
```

## 说明

- 角色动作与程序逻辑分开：新增动作只需放入 `src/assets/` 并登记 `manifest.json`。
- 截屏、聊天、语音只用于当前交互，不会写入磁盘；图片/音频以内存数据发送给模型或播放。
- 所有平台工具均为只读；不包含购物、支付、订单、消息发送和文件上传能力。
- 角色设定、情绪阶段和对话提示词属于运行时内部内容，不在 README 中展开。
