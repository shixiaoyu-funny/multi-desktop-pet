# multi-desktop-pet

Raven 与 Suki 两个 Windows 透明桌宠的仓库。

- `main`：本总述 README
- `raven`：Raven 桌宠项目
- `suki`：Suki 桌宠项目

两个桌宠各自独立维护、各自发布，互不影响。

## 分支与下载

| 角色 | 分支 | 说明 |
|---|---|---|
| Raven | [`raven`](https://github.com/shixiaoyu-funny/multi-desktop-pet/tree/raven) | 黑红配色、高冷傲娇系桌宠 |
| Suki | [`suki`](https://github.com/shixiaoyu-funny/multi-desktop-pet/tree/suki) | 粉蓝配色、治愈元气系桌宠 |

下载请到各自分支的 GitHub Release：

- Raven：<https://github.com/shixiaoyu-funny/multi-desktop-pet/releases>
- Suki：<https://github.com/shixiaoyu-funny/multi-desktop-pet/releases>

## 运行要求

- Windows 10/11
- WebView2 Runtime
- AI 聊天 / 语音需要配置 `DASHSCOPE_API_KEY`
- 未签名 exe 首次运行可能触发 SmartScreen

## DSH 插件

- Raven DSH 插件：<https://github.com/shixiaoyu-funny/raven-dsh-plugin>
- Suki DSH 插件：<https://github.com/shixiaoyu-funny/suki-dsh-plugin>
