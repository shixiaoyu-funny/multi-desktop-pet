## 2. 背景与抠像结论（重要）

角色的不透明像素颜色统计：

- 绿色：**0.0%**
- 蓝/青：7.5%
- 粉/红：38.6%
- 白色：21.7%

所以 **纯绿 #00FF00 是最佳幕布**；蓝色会被头发/开衫吃掉，品红会和粉色冲突，白色会和白丝/白鞋冲突。

不要用“白底视频 + 后期抠白”：
- 角色本身有 21.7% 白色（白丝、白鞋、蕾丝），白色 key 会把腿和鞋一起抠掉。
- 现有 `透明正比立绘.png` 的边缘有烘焙进去的白边：约 2.2 万个半透明像素，其中 42% 接近纯白；这是白底抠图残留，不是角色设计。
- 白边可以做去色/侵蚀，但会伤头发丝；只能做测试，不能作为最终素材。

**最终建议：生成阶段就用纯绿背景。**  
最干净的顺序是：

1. 用原白底正比图做一次“只换背景”的图像编辑：纯绿 #00FF00、无阴影、无地面、保留白丝/白鞋。
2. 检查白鞋边缘、发丝、裙摆蕾丝没有被绿边污染。
3. 把绿底图作为 Wan 的 `first_frame`，生成视频。
4. 视频输出后再 key 绿幕；不要在生成前用白底成品硬抠。

现有透明立绘只能做“管线预演”；正式动作必须换绿底源图。

## 3. 角色特征

- 粉→青蓝渐变超长双马尾，齐刘海，粉紫瞳
- 蓝色贝雷帽、金色星形/蝴蝶结发饰
- 粉色高腰连衣裙 + 蓝色泡泡袖开衫，蕾丝裙边、缎带
- 白色连裤袜、白色厚底运动鞋
- 气质：甜美、轻盈、童话感；动作应有“软、轻、飘”的感觉

### 动作重点

1. 双马尾：延迟跟随、左右不同步、发尾衰减
2. 裙摆：滞后于髋部，落下后继续轻摆
3. 开衫：袖子/下摆跟随肩部，不能穿手臂
4. 缎带/饰物：小幅延迟，不能消失或乱抖
5. 脚底：白鞋必须稳定踩地，不能滑步/漂浮
6. 贝雷帽：头部转动时不能漂移

## 4. Wan 3.0 Prime 参数

官方文档：<https://www.alibabacloud.com/help/zh/model-studio/wan3-video-generation-guide>  
Prompt 指南：<https://www.alibabacloud.com/help/zh/model-studio/wan3-video-generation-prompt-guide>

- 模型：`wan3.0-video-prime`（同系列也支持 `wan3.0-video`）
- 输出：最高 1080P，30fps，MP4
- 时长：2–30 秒；**默认 3 秒**（720P），需要更长回落时再 4 秒
- 成本策略：**720P + 3s 作为默认成品规格**，直接当第一条候选，不先跑 1080 草稿；1080P + 4s 只在 720 边缘/动作确实不合格时单独补
- 建议试片参数：
  - `resolution: 720P`
  - `ratio: adaptive`
  - `duration: 3`
  - `audio: false`（不要自动台词/BGM/音效）
  - `prompt_extend: false`（先手动控制提示词；需要时再开）
- 输出 30fps → 后期 RIFE/FILM 补到 60fps；先检查发尾/蕾丝/手指是否果冻。

## 5. 第一条试片提示词（站姿待机）

> 首帧：把 `透明正比立绘.png` 合成到纯绿 #00FF00 的 1080×1440 画布上，角色居中，脚底在画面 94% 高度，保留完整鞋子。  
> 注意：这是“首帧图”，不是参考图，避免 Wan 把绿幕当风格。

```text
2D 日系动画，单镜头，固定机位，全身入画，角色以首帧图为准。
角色：粉蓝渐变双马尾、蓝色贝雷帽、粉紫瞳、粉色高腰连衣裙、蓝色泡泡袖开衫、白色连裤袜、白色运动鞋、金色星形发饰。
纯绿色背景 #00FF00，无阴影，无地面，无环境元素。
镜头完全固定，不推拉、不摇移、不缩放、不切镜。

动作（0-3 秒）：
她自然站立，双脚稳定踩地，重心轻微左右转移；
胸腔随呼吸缓慢起伏，眨眼一次，头部极轻微侧倾；
双马尾比头部延迟 2-3 帧跟随，发尾缓慢回落；
裙摆和开衫下摆随呼吸轻摆，缎带轻微晃动；
最后回到与首帧几乎相同的站姿，形成可循环的待机。

物理：
双脚不滑动、不漂浮；膝盖微屈；髋部带动裙摆，裙摆有轻微滞后和回摆；
开衫袖子不穿透手臂；双马尾不穿过身体；贝雷帽和发饰固定在头上；
角色比例、服装结构、发色、瞳色全程不变。

风格：
干净 2D 赛璐璐动画，清晰线稿，柔和粉蓝配色，与首帧完全一致。

负向：
不要写实、不要 3D、不要换脸、不要服装变化、不要多手多脚、不要手指畸形、
不要头发穿模、不要裙摆穿腿、不要帽子/发饰消失、不要脚滑、不要漂浮、
不要镜头运动、不要缩放、不要裁切、不要阴影、不要地面、不要文字、不要水印、不要 BGM、不要台词。
```
