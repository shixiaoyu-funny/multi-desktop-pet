让 Raven 能开口

聊天使用阿里云百炼 qwen3.8-flash

1 打开百炼控制台，创建一个 API Key

API Key 以 sk- 开头；不要把它发到公开仓库。

2 把 Key 写进用户环境变量

在 PowerShell 里执行（把 sk-... 换成你的 Key）：

setx DASHSCOPE_API_KEY "sk-..."

也可以：系统属性 → 环境变量 → 用户变量 → 新建 DASHSCOPE_API_KEY。

3 让运行中的桌宠重新检测

点下面的「重新检测」即可；如果仍读不到，再从托盘退出 Raven 重新打开。
